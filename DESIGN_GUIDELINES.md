# varispeed design decisions

This project follows [`lutera_product_guidelines.md`](lutera_product_guidelines.md). The canonical cross-project copy is also saved in ChatGPT Library at `/lutera_product_guidelines.md`.

## varispeed specifics

- Use the warm ivory and champagne atmosphere with cool chrome and graphite materials.
- Keep the large, two-tone editorial `varispeed.` title.
- Keep the doorway in the hero and fully reveal the rounded crown.
- Locate Updates in the hero instead of an extra navigation bar.
- Show one centered lowercase `lūtera` wordmark in the footer.
- The collection and Add tracks action should stay usable while scrolling.
- Keep original and transformed waveforms visible, with precise time readouts, A/B switching, and the optional pan cue.
- In Reference mode, estimate the speed-coupled pitch adjustment from aligned audio timing, not raw file duration. Display the confidence level and avoid displaying a misleading result when the files do not match.
- Exact-cent resampling remains the default; avoid unverified pitch shaping.
- Version numbers belong in release metadata and the Updates menu, not repeated throughout the interface.
